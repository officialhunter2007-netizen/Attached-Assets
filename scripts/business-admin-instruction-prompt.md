# Prompt: توليد ملف تعليمات إدارة الأعمال v4.1 لمنصة نُخبة

---

## دورك

أنت مهندس منهج خبير في تعليم إدارة الأعمال والعلوم الإدارية. مهمتك إنشاء **ملف تعليمات v4.1 كامل لتخصص إدارة الأعمال** يُنشر مباشرةً على منصة تعليمية ذكية يمنية.

### شروط النجاح الصارمة
1. الملف JSON صالح syntactically — يُحقَّق بـ `JSON.parse()` بدون استثناء.
2. لا خطأ واحد يمنع النشر في المدقق.
3. كل `prerequisite_units` / `enables_units` / `prerequisite_lessons` / `enables_lessons` يشير لكود موجود فعلاً.
4. كل معمل يحتوي **بالضبط 5 أسئلة** بأنواع: diagnostic, decision, application, analysis, connection (كل نوع مرة واحدة).
5. كل MCQ فيه choices (≥ 2) وcorrect_index صالح.
6. لا دورات (cycles) في الـ prerequisites.

### الترقيم
```
level_index:  1, 2, 3 — لا تكرار
stage_index:  1..7 داخل كل مستوى — لا تكرار
unit_index:   1..9 داخل كل مرحلة — لا تكرار
lesson_index: 1..10 داخل كل وحدة — لا تكرار
```

### رموز الكيانات
```
كود المرحلة: "L.S"     مثل "1.1"
كود الوحدة:  "L.S.U"   مثل "1.1.1"
كود الدرس:   "L.S.U.N" مثل "1.1.1.1"
```

### المعمل — 5 أسئلة بالضبط
```
diagnostic | decision | application | analysis | connection
كل نوع مرة واحدة فقط — لا تكرار
```

### MCQ
```
choices: مصفوفة ≥ 2 عناصر
correct_index: بين 0 و (choices.length - 1)
```

```
name, goal, bridge_sentence (≥10 كلمات),
prerequisite_lessons ([]), enables_lessons ([]),
concepts (≥1), common_mistakes (≥1), yemeni_examples (≥1),
final_check_question, session_complete_criterion

```
name (فريد داخل الدرس), explanation, mastery_criterion, weight ≥ 1
مجموع الأوزان > 0
